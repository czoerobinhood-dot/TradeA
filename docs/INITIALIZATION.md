# TradeA 成员初始化教程

本文用于首次创建 TradeA 管理员，并把当前浏览器中的本机收藏迁移到 Cloudflare D1。生产地址：

[https://tradea-3al.pages.dev/](https://tradea-3al.pages.dev/)

当前生产环境已经完成首次初始化。最高权限管理员凭据只保存在本机非同步目录 `%LOCALAPPDATA%\TradeA\owner.vars`；网页登录账号使用普通成员角色，不能管理成员或审核训练反馈。本文同时保留环境重建时需要的完整步骤。

本机通过 `run.cmd` 打开 `http://127.0.0.1:8765/` 时，会由服务端读取 `%LOCALAPPDATA%\TradeA\owner.vars` 并自动核验主管理员身份，不需要在浏览器再次输入账号和密码。此自动登录只在固定入口 `127.0.0.1` 启用，凭据和云端会话 Cookie 不会写入网页或浏览器存储；服务关闭时会注销云端会话。服务不会读取项目根目录或 OneDrive 中的 `.owner.vars`；如果系统没有 `LOCALAPPDATA`，自动登录会禁用且不会回退。

## 开始前确认

1. 使用保存了收藏的同一个浏览器和浏览器配置打开生产地址。
2. 页面收藏筛选应显示“收藏 7”。如果显示 0，先不要初始化，说明当前不是保存收藏的浏览器会话。
3. 页面右上角应显示“初始化成员”。
4. 本机项目根目录中的 `.dev.vars` 应存在，并且被 Git 忽略。

当前这 7 只本机收藏是：

- 道明光学 `002632`
- 北玻股份 `002613`
- 海看股份 `301262`
- 振江股份 `603507`
- 夏厦精密 `001306`
- 德力佳 `603092`
- 青岛金王 `002094`

收藏只表示人工认为值得继续观察，不代表买入建议、收益预测或训练正样本。

## 第一步：读取初始化口令

在本机打开项目根目录下的 `.dev.vars`。文件格式为：

```text
SETUP_TOKEN=这里是真实初始化口令
```

只使用等号右侧的值。不要把真实口令粘贴到聊天、截图、Git、README 或任何公开页面中。

如果 `.dev.vars` 不存在，或网页显示“初始化未配置”，应先停止操作并检查 Cloudflare Secret；不要自行生成第二套口令覆盖线上配置。

## 第二步：创建唯一管理员

1. 打开 [TradeA 生产站点](https://tradea-3al.pages.dev/)。
2. 点击右上角“初始化成员”。
3. 填写“成员名称”，例如本人常用显示名称，最长 40 个字符。
4. 填写“管理员账号”，长度为 3-32 个字符，之后登录使用该账号。
5. 填写管理员密码，长度为 12-128 个字符，并使用未在其他网站使用过的独立密码。
6. 在“初始化口令”中填写 `.dev.vars` 里 `SETUP_TOKEN=` 后面的值。
7. 点击“创建管理员”。

管理员创建成功后会自动登录。页面右上角应显示管理员的成员名称，而不再显示“初始化成员”。首次管理员只能创建一次；再次提交初始化表单会被服务器拒绝。

密码不会保存到仓库。服务端只保存 PBKDF2-SHA256 派生结果和独立随机盐，会话通过 `HttpOnly` Cookie 保存。

## 第三步：导入 7 只本机收藏

必须在原来显示“收藏 7”的浏览器中完成本步骤。

1. 登录后打开成员中心。
2. 点击“导入本机收藏”。
3. 等待“本机收藏已导入”提示。
4. 检查“共享收藏”数量和股票代码，确认上述 7 只均已出现。
5. 刷新网页，确认收藏筛选仍显示 7。

登录时，网页会先备份原本的本机收藏，再切换到当前成员的 D1 收藏。导入按钮读取的就是这份备份，因此不要在导入完成前清理浏览器数据、使用隐私模式或更换浏览器配置。

## 第四步：验证跨浏览器同步

1. 在另一个浏览器或另一台设备打开生产站点。
2. 点击“成员登录”。
3. 使用刚创建的管理员账号和密码登录。
4. 确认共享收藏中仍有相同的 7 只股票。
5. 退出后，网页会恢复该浏览器登录前的本机收藏。

初始化完成后的状态接口应返回：

```json
{
  "setupRequired": false,
  "setupReady": true
}
```

只应检查布尔状态，不要在诊断输出中打印 Cookie、密码或初始化口令。

## 第五步：创建普通成员

管理员登录后，可以在“成员管理”中创建普通成员：

1. 填写成员名称。
2. 填写账号，长度为 3-32 个字符。
3. 设置 4-128 个字符的初始密码。管理员密码仍必须至少 12 位。
4. 点击“创建成员”。
5. 通过私下、安全的方式把账号和初始密码交给对应成员。

管理员可以停用或恢复普通成员。当前系统没有自助找回密码功能，不要通过删除 D1 数据来处理忘记密码。

## 第六步：收藏、标注与训练反馈

- 登录状态下点击星标，会更新当前成员的 D1 收藏，并进入成员共享收藏列表。
- 管理员可在“成员收藏明细”中查看每个账号分别收藏的股票；普通成员看不到完整收藏人清单，共享列表仍会显示首次添加者。
- 点击“标注”可以填写日K/周K、观察日期、观察/正样本/反例、置信度和说明。
- 申请进入训练集后，状态先变为 `pending`。
- 只有管理员可以批准或拒绝训练反馈。
- 训练反馈导出只包含管理员批准的数据，不会自动修改筛选规则。

收藏和主观标注不是机器学习效果或盈利证据。导出后仍需检查样本日期、未来区间、负样本和样本外表现。

## 常见问题

### 页面显示“收藏 0”，但原浏览器有收藏

本机收藏属于浏览器的 `localStorage`，不同浏览器、浏览器配置和隐私窗口互不共享。回到截图中显示“收藏 7”的原浏览器，完成登录和“导入本机收藏”。

### 地址出现 `#stock-603507`

这是旧版“本页K线”的页面定位锚点，不是收藏地址。当前生产版本会在完成定位后自动恢复为干净地址：

```text
https://tradea-3al.pages.dev/
```

### 显示“初始化口令错误”

确认只填写 `.dev.vars` 中等号右侧的值，没有多余空格或引号。不要在网页之外传输真实口令。

### 显示“管理员已经初始化”

说明管理员已创建，应关闭初始化表单并使用“成员登录”。不要清空数据库后重新初始化。

### 显示“成员数据库尚未绑定”或“成员服务暂时不可用”

停止初始化，检查 Pages production/preview 的 D1 绑定名是否为 `DB`，并确认最新部署成功。不要把数据库 ID、OAuth Token 或 Secret 写入仓库。

## 完成标准

- 右上角不再显示“初始化成员”。
- 管理员退出后能够重新登录。
- 7 只本机收藏已出现在共享收藏中。
- 管理员的“成员收藏明细”显示收藏账号及其对应股票。
- 另一浏览器登录后能看到同一收藏列表。
- 普通成员无法访问管理员审核和成员管理操作。
- 页面仍不能从公网触发本地股票扫描。
